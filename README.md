# 福ちゃん — 作る毎日を覚えて、売り場で代わりに語る招き猫

Built with Claude: Japan 2026 の提出作品。小さく作って小さく売る人のための Web アプリです。作っている毎日を手帳に写真と一言で残すと、福ちゃんが覚えていきます。売り場では、古いタブレットの中の招き猫が、その話をお客さんに秋田弁で語ります。

## なぜ

小さく作って売る人は、口下手で、売り場に立ち続けることもできません。産直や無人の棚に品物だけ置いても、どう育てたかは誰にも伝わりません。

作った人は農家でもエンジニアでもありません。今年はじめて Claude と一緒に野菜を育てて、来年は庭で採れたものを小さく売ってみたいと思いました。**無人販売の実績はまだありません。** このアプリはその準備として作っています。

ふつうのチャットとの違いは三つです。書くほどこの人の仕事を覚える。聞かなくても必要な時は向こうから言い出す。売り場で、覚えた話を語る。

## できること

頭は一つ（Claude Managed Agents）で、顔が二つあります。猫は店番ではなく、作り手の代わりに語る語り手です。会計も、在庫も、お客さんとの会話もしません。

**お店の手帳**（`techo.html`、スマホのホーム画面に置く）

- 写真（4枚まで）と一言を書くと、福ちゃんが読んで短く返事をします。聞きたいことを書けば相談になります
- 初日は「何を作っていますか」など一つずつ聞いて、最初のノートを作ります
- 投稿を消すと、手帳と店先から消え、福ちゃんのノートも片付けます
- 「お店」の面で、今の札、店先で今日話すセリフ（嫌なものは × で消す）、店に出す写真を選びます。写真に印を付けると、福ちゃんがその場で、記録をもとに売り込みの一言を書きます

**朝のひとこと**：毎朝 7:30 にクラウドで福ちゃんが起きて、ノートと天気予報から、必要な時だけ手帳の一番上に書きます（長くても 3 文、何もなければ一行）。パソコンは要りません。

**夢**：毎晩 3:00 に、ノートの離れた記憶を二つ出会わせて、気づきを一文だけ書きます。夢は連想で、事実の記録ではありません。

**店先の猫**（`index.html`、売り場の古い iPad）

- 開店すると、作り手が印を付けた写真が順に流れ、小さい福ちゃんが一枚ごとに、口下手な作り手の代わりに売り込みの一言を声で言います。人がいてもいなくても止めません
- 人が来ると「いらっしゃい」を足します。写真が一枚もない時だけ、大きな福ちゃんが今日の話を順に話します。猫はその場で考えません
- 猫の端末に合言葉は置きません。読めるのは札とセリフと、店に出す印の付いた写真だけです
- iPad のアクセスガイド（設定 → アクセシビリティ）で画面を固定して使います

**できないこと**：お金の確認と売上・在庫の記録。お客さんとの会話（聞き取りはしません）。人かどうかの判定（画面の変化で見ます。人数は数えません）。

## しくみ

```
 定時起動（朝 7:30・夢 3:00）
          │
          ▼
   福ちゃん（Claude Managed Agents, claude-opus-5-5）＋ メモリストア（ノート）
          ▲
          │ 記録・ノート・札とセリフ
          ▼
   Vercel の API（api/techo） ─ 声（api/koe → Gemini TTS）
        ▲                 ▲
  お店の手帳（techo.html）  店先の猫（index.html）
```

| 場所 | 役割 |
|---|---|
| `agent/system.md` `morning.md` `yume.md` | 福ちゃんの人柄と、朝と夢の指示 |
| `agent/setup.mjs` | 福ちゃんの本体（環境・エージェント・メモリストア・定時起動）を作る／更新する |
| `api/techo/index.js` | 手帳と猫の裏側。API キーはサーバー側だけ |
| `api/koe.js` | セリフを Gemini TTS で読み上げる |
| `home/asa.mjs` | おまけ。家の Mac とカメラがあれば毎朝の写真を渡す |

ノートは `shigoto.md`（作るもの）・`kiroku/YYYY-MM.md`（出来事）・`keikaku.md`（計画と約束）・`tenshu.md`（好み）に分け、どの行も「店主談」「写真で確認」「推測」を区別して書きます。実行環境からネットに出られるのは天気予報の API だけです。費用は 1 会話あたり 1 ドルを上限にしています。

## プライバシー

- 店先は録画も保存も送信もしません。32×24 の小さな灰色の画面を背景と比べるだけで、顔は覚えず、人数も数えません。マイクも使いません
- 記録の写真は Anthropic の API へ送られ、会話の履歴に残ります。人の顔や表札が写った写真は送らないでください
- 猫のセリフは読み上げのために Google の Gemini API へ送られます
- 「消す」で、手帳と店先の表示、返事、ノートの該当行は消えます。Managed Agents の会話の履歴は発言ごとには消せないため、同じ会話に他の投稿が残っている間は Anthropic の側に残ります
- このリポジトリに API キー、合言葉、写真、ノートの中身は入っていません

## 自分で動かす

Claude Managed Agents を使える Anthropic の API キー、Node.js、Vercel のアカウントが要ります。

```sh
npm install
rm agent/ids.json                      # 作者の番号を消す
ANTHROPIC_API_KEY=... node agent/setup.mjs
```

作ったものの番号が `agent/ids.json` に保存されます。Vercel がこの番号を読めるように、このファイルを commit するか、下の `MANEKI_*` の環境変数を設定してください。二回目以降は指示と定時の設定だけを更新します。

リポジトリを Vercel につないで、環境変数を設定します。

| 環境変数 | |
|---|---|
| `ANTHROPIC_API_KEY` | 必須 |
| `SHOP_CODE` | 必須。合言葉 |
| `GEMINI_API_KEY` | 任意。なければ猫は吹き出しだけになります |
| `MANEKI_AGENT_ID` `MANEKI_ENVIRONMENT_ID` `MANEKI_STORE_ID` | 任意。なければ `agent/ids.json` を読みます |

手帳は `/techo.html`、店先の猫は `/` です。手帳を置いたら定時起動を動かします。

```sh
ANTHROPIC_API_KEY=... node agent/setup.mjs --start   # 止める時は --stop
```

おまけのカメラ係（`home/asa.mjs`）は、ffmpeg と RTSP のカメラがある人向けです。使い方はファイルの頭に書いてあります。
