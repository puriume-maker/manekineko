# 福ちゃん — 庭を覚えていく相棒の招き猫

Built with Claude: Japan 2026 の提出作品です。

## 何か

一人では始められなかった庭仕事を、その庭を覚えていく相棒と一緒に始めて、いつか庭先で売るところまで付き合う Web アプリです。

頭は一つで、顔が二つあります。

- **お店の手帳**（`techo.html`）：店主がスマホで開く画面。今朝の庭の写真と福ちゃんのひとことが主役で、話しかけることもできます
- **店先の猫**（`index.html`）：庭先に置いた古いタブレットで動く招き猫。福ちゃんが書いた言葉を秋田弁で読み上げます

## なぜ

作った人は農家でもエンジニアでもありません。今年はじめて Claude と一緒に野菜を育てて、それが楽しくて、来年は庭で採れたものを庭先で小さく売ってみたいと思いました。

**無人販売の実績はまだありません。一つも売っていません。** 来年試す段階で、このアプリはその準備として作っています。

ふつうのチャットとの違いは三つです。この庭をカメラで実際に見ること、前に話したことや失敗を覚えていること、話しかけなくても必要な時は向こうから言い出すことです。

## できること

### 朝の見回り

家の Mac で動く係（`home/asa.mjs`）が 1 日 1 回、庭のカメラで写真を 1 枚撮って福ちゃんを起こします。福ちゃんは記憶のノートを読み、写真を見て、必要なら天気予報（Open-Meteo）を調べて、店主へのひとことを書きます。

- 長くても 3 文。変化がなく伝えることもない朝は短い一行だけ
- 見えないものは断定せず、写真に庭が写っていなければそう言う
- 7 日前にいちばん近い写真があれば、見比べる。カメラが撮れない朝は、撮れなかったことを伝える

### 記憶

福ちゃんの記憶は Managed Agents のメモリストア（以下、ノート）だけです。会話が変わっても、ノートに書いたことは残ります。

- `niwa.md`（土地と庭）、`kiroku/YYYY-MM.md`（月ごとの出来事）、`keikaku.md`（計画と約束）、`tenshu.md`（店主の好み）に分けて書く
- 「店主談」「写真で確認」「推測」を区別して書く。提案と約束も区別する
- 店主は手帳からノートをそのまま読める

### 夢

朝の見回りの前に一度、ノートの中の離れた記憶を二つ出会わせて、気づきを一文だけ `yume.md` に書きます。結びつきが弱い日は「今夜は静か」とだけ書きます。

夢は連想で、事実の記録ではありません。新しい事実を足さないこと、推測は推測と書くことを指示しています（`agent/yume.md`）。役立ちそうな時だけ、朝のひとことに一文添えます。公式の夢の機能は使わず、ふつうの会話として自作しました。

### 手帳

- 今朝の写真とひとこと。最近 7 回分の朝を見返せる
- 文章と写真で福ちゃんと話せる
- 福ちゃんのノートを読める
- 合言葉で閉じている

### 店先の猫

- 前面カメラで動きを見て、通りすぎる人には声を出さずに手を振る
- 4 秒ほどとどまると、声をかけて、福ちゃんがその朝に書いた今日の話を順に話す
- 猫はその場で考えません。福ちゃんがノートの `mise.json` に書いた札とセリフを読むだけです。セリフが読めない時は決まり文句を使います
- 声が作れない時は吹き出しだけになります
- だれも来なければ寝ます

### できないこと

- お金を入れたかどうかの確認、売上や在庫の自動の記録（箱のお金は店主が話した時だけわかります）
- お客さんとの会話。猫は聞き取りをしません
- 人かどうかの判定。立ち止まりは画面の変化で判断するので、人数はあくまで目安です

朝の見回りは動き始めたばかりで、写真を見比べる動作はまだ実際の写真で確かめていません。

## しくみ

```
庭のカメラ → 家の Mac のカメラ係（home/asa.mjs）
                      │ 写真と朝の合図
                      ▼
            福ちゃん（Claude Managed Agents）
              頭：claude-opus-5-5 ／ 記憶：メモリストア
                      ▲
                      │ 会話・ノート・札とセリフ・立ち止まった人数
                      ▼
            Vercel の API（api/techo） ─ 声（api/koe → Gemini TTS）
                 ▲                ▲
        お店の手帳（techo.html）   店先の猫（index.html）
```

| 場所 | 役割 |
|---|---|
| `agent/system.md` `morning.md` `yume.md` | 福ちゃんの人柄と、朝と夢の指示 |
| `agent/setup.mjs` | 福ちゃんの本体（環境・エージェント・メモリストア）を作る／更新する |
| `home/asa.mjs` | カメラ係。夢を見せてから、写真を撮って朝の会話を始める |
| `api/techo/index.js` | 手帳と猫の裏側。API キーはサーバー側だけに置く |
| `api/koe.js` | セリフを Gemini TTS で読み上げる |

福ちゃんの実行環境からネットに出られるのは天気予報の API だけです。費用の上限は 1 会話あたり 1 ドルに設定しています。Managed Agents はベータ版の機能です。定時実行の機能（deployment）は作ってありますが止めていて、朝は家のカメラ係が起こします。Mac が眠っていたりカメラに届かなかったりすると、その朝は動かないか、写真なしになります。

## プライバシー

- **顔を覚えません。** 顔認識のコードはありません
- **店先は録画しません。** 32×24 の灰色の小さな画面を約 0.4 秒おきに背景と比べるだけで、画像は保存も送信もしません。マイクも使いません。カメラを使っていることは画面に書いて出します
- **数えるのは立ち止まった人数の目安だけです。** ノートに残るのは日付と人数だけです

店先とは別に、庭のカメラの写真は扱いが違います。朝の 1 枚は家の Mac に保存され、Anthropic の API へ送られて会話の履歴に残ります。手帳で送った写真も同じく API へ送られます。画角に人が入らないように置くのは店主の役目です。

猫のセリフは読み上げのために Google の Gemini API へ送られます。合言葉と作った声は、使っている端末のブラウザに残ります。

このリポジトリには、API キー、合言葉、カメラの接続先、庭の写真、ノートの中身は入れていません。

URLと合言葉は提出フォームに記載しています。

## 自分で動かす

Claude Managed Agents を使える Anthropic の API キー、Node.js、Vercel のアカウントが要ります。朝の見回りには ffmpeg と RTSP で映像を取れるカメラ、それを見られる常時起動のパソコンも要ります。

```sh
npm install
```

### 1. 福ちゃんの本体を作る（`agent/setup.mjs`）

`agent/ids.json` にはこのリポジトリの作者の番号が入っています。先に消してください。残っていると、作者のエージェントを更新しようとして失敗します。

```sh
rm agent/ids.json
ANTHROPIC_API_KEY=... node agent/setup.mjs
```

作ったものの番号が `agent/ids.json` に保存されます。二回目以降は指示の更新だけをします。

### 2. カメラ係を置く（`home/asa.mjs`）

次の二つのファイルをリポジトリの外に作ります。

| ファイル | 環境変数 |
|---|---|
| `~/.config/manekineko/.env` | `ANTHROPIC_API_KEY` |
| `~/.config/manekineko/camera.env` | `NIWA_CAMERA_RTSP` |

```sh
node home/asa.mjs              # きょうの分がまだなら動く
node home/asa.mjs --force      # きょうの分があっても、夢も朝ももう一度
node home/asa.mjs --yume-only  # 夢だけ
```

定時に動かす設定はリポジトリに入っていません。cron などで 1 日 1 回、リポジトリの場所で `node home/asa.mjs` を呼んでください。写真は `~/.local/share/manekineko/photos` に置かれます。

### 3. Vercel に置く

リポジトリを Vercel につないで、環境変数を設定します。

| 環境変数 | |
|---|---|
| `ANTHROPIC_API_KEY` | 必須 |
| `SHOP_CODE` | 必須。合言葉。未設定だと API は閉じたままです |
| `GEMINI_API_KEY` | 任意。なければ猫は吹き出しだけになります |
| `MANEKI_AGENT_ID` `MANEKI_ENVIRONMENT_ID` `MANEKI_STORE_ID` | 任意。なければ `agent/ids.json` を読みます |

手帳は `/techo.html`、店先の猫は `/` です。合言葉を入れて手帳で福ちゃんに話しかけると、ノートが積もり始めます。売るものと値段を話すと、猫に札とセリフが出ます。

## Claude Code で作りました

開発は Claude Code を中心に進めました。すべてのコミットに Claude の共同作者の行があります。

- **仕様を言葉にする**：コードの前に、専門用語なしの紙一枚で「何を作るか」を人と Claude Code で詰めました
- **小さく試して決める**：Managed Agents の写真の渡し方やメモリストアの使い心地を、決める前に小さく試しました
- **実装と直し**：画面、API、カメラ係、セットアップをコミット単位で作り、試して出た問題を直しました。たとえば、福ちゃんがノートに書いただけで黙った時に一度だけ返事を促す処理や、推測や提案を事実や約束として話さないための指示の調整です
- **画面の確認**：ヘッドレス Chrome でスマホの幅のスクリーンショットを撮って、見た目を確かめました

開発に使った Claude Code の設定やスキルは、プロダクトには含めていません。Claude 以外の AI は、猫の読み上げの Gemini TTS だけをプロダクトの中で使っています。
